## Legal document maintenance

The website provides support, privacy, and terms pages in Simplified Chinese,
English, and Traditional Chinese. Each language selector links to the same
kind of document in the selected language.

The terms originate from the app repository's `Legal/TERMS.html` (effective
July 14, 2026). The Simplified Chinese and English substantive text is retained;
the Traditional Chinese page is a translation of the Simplified Chinese source.
The website's language notice lists all three website versions. When the app's
terms change, review all three website pages together; do not change the
effective date solely for a website layout or translation update.
