选了视频，加不上

在「记录」打开这节课，点铅笔进入编辑，再点「视频」里的「＋」。从系统「照片」选一段视频，看到它出现在编辑页后点右上角「保存」。如果视频还在聊天或「文件」里，先把它存入「照片」。只想记课时，可以先保存记录，以后再加视频。

第一次授权，或之前点过不允许。 第一次选片时，可以只允许访问需要的片段。看到「未允许访问相册。」就点「打开设置」，调整练完啦的照片权限。回来后要新增视频，点「＋」。要替换缺片，点原缩略图上的「重新选择」。若提示「此设备限制了相册访问。」，请向能管理这台设备的人核对限制。你仍可以保存其他练习内容。

选片器看得到，选完却提示「无权访问这条视频。」 点编辑页的「管理相册权限」，把刚才选的那一段加入允许范围。回编辑页先看缩略图。刚选的视频已出现，就点「保存」。还在转圈就等。关联结束后仍没加上，沿原入口再选一次并保存。新增点「＋」，替换点原缩略图的「重新选择」。若提示「这个视频已添加」，横向查看本条记录里已有的视频。

右上角的「保存」变成转圈。 先留在编辑页。如果有系统权限询问，先完成选择。已经选好视频、关联较慢时，视频区会出现时钟图标。添加时在原「＋」的位置，替换时在「视频」标题旁边。点它可选「继续等待」或「取消」。等关联完成，或取消本次关联后，再点「保存」保住笔记等修改。

出现感叹号。 点开看提示。若有「重试连接照片」，先点它。若提示重新选择，就点「重新选择」再选一次。替换失败时，原来的关联仍保留。

以前加过的视频，现在播不了

先在出问题的这台设备打开系统「照片」，找到同一段视频并点播放。练完啦的封面可以单独显示，因此看到封面时也要试播原片。

  • 「照片」能播，练完啦提示需要权限。 播放器显示「打开设置」就点它，允许练完啦读取原片。显示「重试」且系统尚未询问权限时，点它可请求授权。若显示「此设备限制了照片访问。」，请向设备管理者核对限制。只允许了部分照片、画面显示「无法访问此视频」时，点「管理相册权限」把这段加回，再试播。
  • 「照片」还在下载，或 App 显示「正在从 iCloud 加载视频」。 接入可用网络，等这段在「照片」能播放，再回练完啦点播放。有「重试」就点它。只显示「视频加载失败」时，可退出播放器再打开，先保留原来的关联。
  • 「暂时无法在照片中找到此视频，请稍后重试。」 在本机「照片」确认仍有原片，稍后回播放器点「重试」。如果系统「照片」也找不到这段，继续看下面两项。
  • 「找不到原视频」，尤其是在新设备上。 到原设备的「照片」查同一段。原来通过 iCloud 照片使用这段视频，就在新设备核对是否使用同一照片图库、原片是否已到达，以及练完啦能否读取它。App 同步练习记录，相册原片由系统「照片」管理。
  • 确认误删。 先去「照片 → 最近删除」恢复原片，再回练完啦试播。通常可在删除后 30 天内恢复。使用 iCloud 照片时，删除也会同步到同一图库的其他设备。Apple 的删除与恢复说明

只剩另一份视频，或挂错了片段。 先把可用的那份存进系统「照片」。在「练习」点缺片缩略图或播放器的「重新选择」，若打开记录详情，点铅笔。到了编辑页，在缺片缩略图上点「重新选择」。若已进入选片器，直接选对的片段，回编辑页「保存」。如果旧片还能正常播放，从「记录」打开这节课，点铅笔进入编辑，用「＋」先加对的那段，再点旧缩略图右上角 × →「删除」→「保存」。这里移除的是这条练习的关联，系统「照片」里的原片会保留。

找不到刚打的卡，或想补记一节课

刚刚长按了唱片。 长按约一秒至进度完成再松手，基础记录就保存了。点「记录这一刻」可补这条的老师、歌曲、笔记和视频，再点「保存」。也可稍后到「记录」找。唱片右下角的 × 是「取消打卡」，点它会删除这条待补打卡。

找不到刚才那条。 「记录」日历下方默认显示最近有记录的一天。点实际练习日期查看当天。凌晨打卡也看看前一天。例如 00:20 打卡，默认记录为前一天 23:15 至当天 00:15，按开始日期归档。填过歌名或老师可以直接搜。刚打卡还没补详情，可以按「状态 → 待补标签/视频」找。

首次打卡要先建个人资料吗？ 首次设置专辑时可以点「稍后再说」，之后想换昵称或唱片中心图，在「打卡」点昵称旁的铅笔。

忘了打卡或找不到「补卡」。 在「记录」里，若正在搜索，先点「取消」回到日历。若日历下已显示目标日期和「补卡」，直接点「补卡」。否则先点要补的日期（今天或以前），再点当日列表下的「补卡」。先选开始或结束时间，另一端会按一小时填上，按实际情况调整后点「保存」。退出未保存的补卡草稿不会新增记录。遇到「时间重叠」，同一节课就取消并找已有记录编辑。确实有两节，点「仍然保存」会保留两条。

已经保存，详情还在读取。 如果详情页出现「重试」就点它。一直打不开，可回到「记录」查看刚选的日期，找到同一条再打开。先核对有几条，再决定是否补卡。如果还停在编辑页、右上角在转圈，请看视频关联中的保存按钮。

换了设备，找不到记录

  1. 原机还在，先确认上面的记录能打开。核对两台使用同一 Apple 账户，在原机打开「记录 → 更多（…）→ 数据与隐私」。若打算用 iCloud 换机，先在原机开启「iCloud 同步」。遇到确认弹窗按下文核对。首次建库时，等原机建好再去新机。也可以先在原机导出备份。
  2. 在新机的同一页面开启「iCloud 同步」，等待原账户已同步的资料到达。原机已不在，如果曾开启同步，可以直接从这一步开始。手上有旧备份，也可以预览并导入。若提示 iCloud 空间不足，检查该账户的 iCloud 可用容量。有「再次检查」时再点它。
  3. 到新设备按日期打开几条旧记录，核对笔记、封面，再试播视频。记录到了、视频还没到，转到原片排查。核对完成前保留原机资料。

弹出「重建 iCloud 资料库？」。 在有完整记录的原机上首次开启同步，而且确定该账户还没有练完啦云库时，「重建并上传」会上传这台设备的记录和关联图片。如果正从空的新机找旧资料，先点「取消」，核对原机或已有备份。若找不到任何可确认有资料的副本，请保留现状并联系开发者。

弹出「迁入当前 iCloud 账户？」或「复制旧记录？」。 「迁入记录」会把本机记录与当前账户的记录合并。若本来就想用原账户，先点「取消」，核对账号。确实要迁入且提示照片不可访问时，在有记录的设备上恢复相关原片的读取权限，再开启「iCloud 同步」重试。「复制并加入」会把旧库可见的记录和关联图片复制到新库，之后旧版 App 的改动不会跟到新库。无法确认该用哪一份时，保留现状并联系开发者。

怎么备份、导入或找回误删的记录？

先做一份能恢复的备份。 打开「记录 → 更多（…）→ 数据与隐私 → 导出我的数据」。设置并确认至少 8 个字符的密码，点右上角方框向上箭头，在系统文件选择器选好位置并保存。换机前，确认能在新设备取得这个 .glocue 文件，也记得密码。包里有练习记录、舞卡、所需封面和头像。相册视频只保存关联，原片要另外保存在「照片」或自己的备份中。

导入前能先看看吗？ 可以。在同一页点「导入我的数据」，选择 .glocue 文件，输入导出时的密码，点「预览」。这里可以点「取消」，不会改动本机记录。预览里的「视频」数量包含照片图库引用。备份里没有的本机记录会保留。

想恢复误删记录，或「导入」呈灰色。 使用删除前保存的备份，在预览里核对新增项目。对有差异或在本机已删除的项目，选择「本机」或「备份」。想找回的那条选「备份」。按提示检查相关记录、舞卡、舞室和视频。若提示项目身份不兼容，选「本机」。预览因本机资料变化而刷新后，重新核对选择。确认整份预览后再点「导入」。新增和修改会保存到本机，开启同步时也可能传到其他设备。

文件打不开，或忘了密码。 提示文件不可用，就在「文件」中先下载到本机再选。提示设备空间不足，就先腾出本机空间。若显示「密码不正确或备份已损坏」，核对原密码，并从保存位置重新取完整的 .glocue 文件。旧 JSON 报告不能导入。密码无法找回。若旧机仍能打开记录，可以从旧机重新导出并设置新密码。

导出时提示要处理同步冲突。 打开「数据与隐私 → 查看同步冲突」。先比较两边，再点要保留的「此设备数据」或「其他设备数据」。点下就应用。一般只影响列出的冲突字段，其余更改保留。如果一边显示「已删除」，选它会删除这一项。遇到「接受删除」和「恢复此设备上的版本」时，前者从本机移除该项，后者把本机编辑的版本同步回 iCloud。处理后再导出。若提示缺少关联记录或图片，先查看相关记录和同步状态，待资料可用后重试。

删记录、关同步或卸载会怎样？ 删除练习记录会保留系统「照片」原片。开启同步时，这次删除也可能传到其他设备。关闭「iCloud 同步」会保留本机记录。删除 App 会移除本机副本，换机排查时先保留仍能看到资料的设备及其 App。

「记录」有这节课，「练习」里怎么找？如何保存变速版？

「练习」只列已经关联视频的记录。先移除「练习」里已选的筛选条件。找到那节课后，点视频缩略图开始跟练。同一节有多段，先点带数量的预览展开，再点要练的缩略图。如果还找不到，再回「记录」打开那节课，确认视频已加好并保存。

在「练习」播放器用速度尺调速，用循环图标切换整段重复播放。想另存一份，先把速度调离 1×，再点视频右上角的方框向下箭头（「保存变速视频」），需要时允许添加到「照片」。保持当前片段直到保存结束，去系统「照片」找新副本。若提示需要允许添加到照片，去系统设置调整后再保存。若原片还打不开，先恢复播放。

建了舞卡，为什么次数或时长对不上？

打开那条练习记录，点铅笔，再点「课卡」右侧的「更改」。选中卡后点「保存」。也可以点「新增课卡」，建好后回到练习记录点「保存」。看不到某张卡时，核对练习当天是否在有效期内，以及总次数或该周期的额度是否已用完。

在「记录 → 舞卡」打开卡片，看进度显示的单位。「已用」按关联的练习节数计算。如果目标按打卡天数算，同日两节只加一天。期限型的进度还可能显示有效期已过几天。

在「分析」里，先核对所选日期范围。时长来自每条记录填写的时间。补卡时留空起止时间也会默认计 60 分钟。要改某一节，回到「记录」打开详情，点铅笔调整时间并保存。

怎么分享回顾？ 在「分析」选有练习数据的日期范围，点右上角分享图标。在「分享内容」取消不想公开的「含名称」卡片，至少留一张。滑动核对预览，选了展示老师或歌曲名称的卡片，这些名称也会出现在分享图上。最后点右上角的分享图标，选择发送或保存方式。

联系开发者

支持邮箱 realrael.dev@outlook.com 。请写上 App 版本、设备型号、系统版本、卡在哪一步，以及屏幕提示的原文。视频问题请注明同一段能否在该设备的「照片」里播放。截图可遮住名字和笔记。请勿附备份文件、密码、验证码或私人视频。开发者无法查看或恢复你的私人 iCloud 资料。

网站托管

本支持及隐私政策网站使用 GitHub Pages 托管。访问这些网页时，GitHub 会出于安全目的记录并保存访问者的 IP 地址，无论您是否登录 GitHub。相关信息由 GitHub 按其隐私声明处理。此处理发生于网站访问，不表示 GloCue 在 App 内加入行为追踪、广告或第三方分析。有关详情，请参阅 GitHub 隐私声明。
