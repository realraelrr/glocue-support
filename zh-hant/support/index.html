練完啦支援

練完啦（GloCue）幫助你記錄舞蹈練習、整理課堂筆記、連結練習影片及管理舞卡。適用於 iOS 17+ 的 iPhone 與 iPadOS 17+ 的 iPad。

如何記錄一次練習？

在打卡頁面長按打卡，先留下當天記錄，再補充老師、課程類型、歌曲、課程時數、筆記及所選影片。也可以瀏覽、編輯已有記錄，在日曆與搜尋中找到它們。

不登入 iCloud 可以使用嗎？

可以。練習記錄由本機提供，iCloud 無法使用不影響已有本機記錄的查看和編輯。你可以在「資料與隱私」中選擇是否開啟 iCloud 同步。跨裝置同步需要同一 Apple 帳號及可用的 Apple 服務；同步並不保證即時完成。

為什麼另一部裝置看不到影片？

如果連結的是相簿影片，原始影片仍由照片圖庫管理。另一部裝置需要相應的照片權限、同一 iCloud 照片圖庫，並等待原始影片同步或下載。檢查能否在 Apple 照片中開啟原始素材，以及裝置網路與儲存空間。影片連結不等於獨立備份；刪除原始素材或變更權限可能使影片無法播放。

為什麼 iCloud 同步暫時無法使用？

檢查「資料與隱私」中的同步設定、Apple 帳號、網路與 iCloud 可用空間。遇到帳號不一致時，應用程式會保留本機內容並暫停同步，不會自動將原帳號的資料轉移至新帳號。請勿為了排查問題先移除應用程式或刪除 iCloud 資料；若仍有問題，可透過電子郵件聯絡。

如何匯出或刪除資料？

在「資料與隱私」中使用資料匯出功能，可匯出本機完整可用記錄的 JSON 報告。報告不包含媒體檔案，也不是可匯入的備份。你可以在應用程式內刪除記錄；移除影片連結或解除安裝 App 不會自動刪除全部雲端媒體。具體保留與刪除規則請見隱私政策。

如何變更照片權限？

在系統設定中找到練完啦的照片存取權限，依需求調整。撤銷權限可能影響已連結素材的播放與處理。

網站託管

本支援及隱私權政策網站使用 GitHub Pages 託管。造訪這些網頁時，GitHub 會基於安全目的記錄並儲存訪客的 IP 位址，無論您是否登入 GitHub。相關資訊由 GitHub 依其隱私聲明處理。此處理發生於網站造訪，不表示 GloCue 在 App 內加入行為追蹤、廣告或第三方分析。詳情請參閱 GitHub 隱私聲明。
