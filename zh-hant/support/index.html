選了影片，加不進去

在「記錄」打開這節課，點鉛筆進入編輯頁，再點「影片」裡的「＋」。從系統「照片」選一段影片，看到它出現在編輯頁後點右上角「儲存」。如果影片還在聊天或「檔案」裡，先把它存入「照片」。只想記課時，可以先儲存記錄，以後再加影片。

第一次授權，或之前點過不允許。 第一次選擇影片時，可以只允許存取需要的片段。看到「尚未允許取用相簿。」就點「打開設定」，調整練完啦的照片權限。回來後要新增影片，點「＋」。要替換缺片，點原縮圖上的「重新選擇」。若提示「此裝置限制了相簿取用權限。」，請向能管理這台裝置的人核對限制。你仍可以儲存其他練習內容。

影片選擇器看得到，選完卻提示「無權取用這部影片。」 點編輯頁的「管理相簿權限」，把剛才選的那一段加入允許範圍。回編輯頁先看縮圖。剛選的影片已出現，就點「儲存」。還在轉圈就等。連結結束後仍沒加進來，回到原入口再選一次並儲存。新增點「＋」，替換點原縮圖的「重新選擇」。若提示「這個影片已加入」，橫向查看這筆記錄裡已有的影片。

右上角的「儲存」變成轉圈。 先留在編輯頁。如果有系統權限詢問，先完成選擇。已經選好影片、連結較慢時，影片區會出現時鐘圖示。加入時在原「＋」的位置，替換時在「影片」標題旁邊。點它可選「繼續等待」或「取消」。等連結完成，或取消本次連結後，再點「儲存」保住筆記等修改。

出現感嘆號。 點開看提示。若有「重試連接照片」，先點它。若提示重新選擇，就點「重新選擇」再選一次。替換失敗時，原來的連結仍保留。

以前加過的影片，現在無法播放

先在出問題的這台裝置打開系統「照片」，找到同一段影片並點播放。練完啦的封面可以單獨顯示，因此看到封面時也要試播原片。

  • 「照片」能播，練完啦提示需要權限。 播放器顯示「打開設定」就點它，允許練完啦讀取原片。顯示「重試」且系統尚未詢問權限時，點它可請求授權。若顯示「此裝置限制了照片取用權限。」，請向裝置管理者核對限制。只允許了部分照片、畫面顯示「無法存取此影片」時，點「管理相簿權限」把這段加回，再試播。
  • 「照片」還在下載，或 App 顯示「正在從 iCloud 載入影片」。 接入可用網路，等這段在「照片」能播放，再回練完啦點播放。有「重試」就點它。只顯示「影片載入失敗」時，可退出播放器再打開，先保留原來的連結。
  • 「暫時無法在照片中找到此影片，請稍後再試。」 在本機「照片」確認仍有原片，稍後回播放器點「重試」。如果系統「照片」也找不到這段，繼續看下面兩項。
  • 「找不到原始影片」，尤其是在新裝置上。 到原裝置的「照片」查同一段。原來透過 iCloud 照片使用這段影片，就在新裝置核對是否使用同一照片圖庫、原始影片是否已同步，以及練完啦能否讀取它。App 同步練習記錄，相簿原片由系統「照片」管理。
  • 確認誤刪。 先去「照片 → 最近刪除」復原原片，再回練完啦試播。通常可在刪除後 30 天內復原。使用 iCloud 照片時，刪除也會同步到同一圖庫的其他裝置。Apple 的刪除與復原說明

只剩另一份影片，或連結錯了片段。 先把可用的那份存進系統「照片」。在「練習」點缺片縮圖或播放器的「重新選擇」，若打開記錄詳情，點鉛筆。到了編輯頁，在缺片縮圖上點「重新選擇」。若已進入影片選擇器，直接選對的片段，回編輯頁「儲存」。如果舊片還能正常播放，從「記錄」打開這節課，點鉛筆進入編輯頁，用「＋」先加對的那段，再點舊縮圖右上角 × →「刪除」→「儲存」。這裡移除的是這條練習的連結，系統「照片」裡的原片會保留。

找不到剛打的卡，或想補記一節課

剛剛長按了唱片。 長按約一秒至進度完成再放開手指，基礎記錄就儲存了。點「記錄這一刻」可補這條的老師、歌曲、筆記和影片，再點「儲存」。也可稍後到「記錄」找。唱片右下角的 × 是「取消打卡」，點它會刪除這條待補打卡。

找不到剛才那條。 「記錄」日曆下方預設顯示最近有記錄的一天。點實際練習日期查看當天。凌晨打卡也看看前一天。例如 00:20 打卡，預設記錄為前一天 23:15 至當天 00:15，按開始日期歸檔。填過歌名或老師可以直接搜。剛打卡還沒補詳情，可以按「狀態 → 待補標籤/影片」找。

首次打卡要先建個人資料嗎？ 首次設定專輯時可以點「稍後再說」，之後想換暱稱或唱片中心圖，在「打卡」點暱稱旁的鉛筆。

忘了打卡或找不到「補卡」。 在「記錄」裡，若正在搜尋，先點「取消」回到日曆。若日曆下已顯示目標日期和「補卡」，直接點「補卡」。否則先點要補的日期（今天或以前），再點當日列表下的「補卡」。先選開始或結束時間，另一端會按一小時填上，按實際情況調整後點「儲存」。退出未儲存的補卡草稿不會新增記錄。遇到「時間重疊」，同一節課就取消並找已有記錄編輯。確實有兩節，點「仍然儲存」會保留兩條。

已經儲存，詳情還在讀取。 如果詳情頁出現「重試」就點它。一直打不開，可回到「記錄」查看剛選的日期，找到同一條再打開。先核對有幾條，再決定是否補卡。如果還停在編輯頁、右上角在轉圈，請看影片連結中的儲存按鈕。

換了裝置，找不到記錄

  1. 原機還在，先確認上面的記錄能打開。核對兩台使用同一 Apple 帳號，在原機打開「記錄 → 更多（…）→ 資料與隱私」。若打算用 iCloud 換機，先在原機查看「iCloud 同步」。還沒開啟且確定要用該帳號時，再開啟。遇到確認彈窗按下文核對。首次建庫時，等原機建好再去新機。也可以先在原機匯出備份。
  2. 在新機的同一頁面確認已開啟「iCloud 同步」，等待原帳號已同步的資料到達。原機已不在，如果曾開啟同步，可以直接從這一步開始。手上有舊備份，也可以預覽並匯入。若提示 iCloud 空間不足，檢查該帳號的 iCloud 可用容量。有「再次檢查」時再點它。
  3. 到新裝置按日期打開幾條舊記錄，核對筆記、封面，再試播影片。記錄到了、影片還沒到，轉到原片排查。核對完成前保留原機資料。

彈出「重建 iCloud 資料庫？」。 在有完整記錄的原機上首次開啟同步，而且確定該帳號還沒有練完啦雲庫時，「重建並上傳」會上傳這台裝置的記錄和連結圖片。如果正從空的新機找舊資料，先點「取消」，核對原機或已有備份。若找不到任何可確認有資料的副本，請保留現狀並聯絡開發者。

彈出「移轉至目前的 iCloud 帳號？」或「複製舊記錄？」。 「移轉記錄」會把本機記錄與目前帳號的記錄合併。若本來就想用原帳號，先點「取消」，核對帳號。確實要遷入且提示照片不可存取時，在有記錄的裝置上恢復相關原片的讀取權限，再開啟「iCloud 同步」重試。「複製並加入」會把舊庫可見的記錄和連結圖片複製到新庫，之後舊版 App 的改動不會跟到新庫。無法確認該用哪一份時，保留現狀並聯絡開發者。

怎麼備份、匯入或找回誤刪的記錄？

先做一份能恢復的備份。 打開「記錄 → 更多（…）→ 資料與隱私 → 匯出我的資料」。設定並確認至少 8 個字元的密碼，點右上角方框向上箭頭，在系統檔案選擇器選好位置並儲存。換機前，確認能在新裝置取得這個 .glocue 檔案，也記得密碼。備份檔裡有練習記錄、舞卡、所需封面和頭像。相簿影片只儲存連結，原片要另外儲存在「照片」或自己的備份中。

匯入前能先看看嗎？ 可以。在同一頁點「匯入我的資料」，選擇 .glocue 檔案，輸入匯出時的密碼，點「預覽」。這裡可以點「取消」，不會改動本機記錄。預覽裡的「影片」數量包含照片圖庫引用。備份裡沒有的本機記錄會保留。

想恢復誤刪記錄，或「匯入」呈灰色。 使用刪除前儲存的備份，在預覽裡核對新增項目。對有差異或在本機已刪除的項目，選擇「本機」或「備份」。想找回的那筆選「備份」。按提示檢查相關記錄、舞卡、舞室和影片。若提示項目身分不相容，選「本機」。預覽因本機資料變化而刷新後，重新核對選擇。確認整份預覽後再點「匯入」。新增和修改會儲存到本機，開啟同步時也可能傳到其他裝置。

檔案打不開，或忘了密碼。 提示檔案不可用，就在「檔案」中先下載到這部裝置再選。提示裝置空間不足，就先騰出本機空間。若顯示「密碼不正確或備份已損毀」，核對原密碼，並從儲存位置重新取完整的 .glocue 檔案。舊 JSON 報告不能匯入。密碼無法找回。若舊機仍能打開記錄，可以從舊機重新匯出並設定新密碼。

匯出時提示要處理同步衝突。 打開「資料與隱私 → 查看同步衝突」。先比較兩邊，再點選要保留的「此裝置資料」或「其他裝置資料」。選擇會立即套用。一般只影響列出的衝突欄位，其餘更改保留。如果一邊顯示「已刪除」，選它會刪除這一項。遇到「接受刪除」和「還原此裝置上的版本」時，前者從本機移除該項，後者把本機編輯的版本同步回 iCloud。處理後再匯出。若提示缺少連結記錄或圖片，先查看相關記錄和同步狀態，待資料可用後重試。

刪記錄、關同步或卸載會怎樣？ 刪除練習記錄會保留系統「照片」原片。開啟同步時，這次刪除也可能同步到其他裝置。關閉「iCloud 同步」會保留本機記錄。刪除 App 會移除本機副本，換機排查時先保留仍能看到資料的裝置及其 App。

「記錄」有這節課，「練習」裡怎麼找？如何儲存變速版？

「練習」只列已經連結影片的記錄。先移除「練習」裡已選的篩選條件。找到那節課後，點影片縮圖開始跟練。同一節有多段，先點帶數量的預覽展開，再點要練的縮圖。如果還找不到，再回「記錄」打開那節課，確認影片已加好並儲存。

在「練習」播放器用速度尺調速，用循環圖示切換整段重複播放。想另存一份，先把速度調離 1×，再點影片右上角的方框向下箭頭（「儲存變速影片」），需要時允許加入到「照片」。保持目前片段直到儲存結束，去系統「照片」找新副本。若提示需要允許加入到照片，去系統設定調整後再儲存。若原片還打不開，先恢復播放。

建了舞卡，為什麼次數或時長對不上？

打開那條練習記錄，點鉛筆，再點「課卡」右側的「更改」。選中卡後點「儲存」。也可以點「新增課卡」，建好後回到練習記錄點「儲存」。看不到某張卡時，核對練習當天是否在有效期內，以及總次數或該週期的額度是否已用完。

在「記錄 → 舞卡」打開卡片，看進度顯示的單位。「已用」按連結的練習節數計算。如果目標按打卡天數算，同日兩節只加一天。期限型的進度還可能顯示有效期已過幾天。

在「分析」裡，先核對所選日期範圍。時長來自每條記錄填寫的時間。補卡時留空起止時間也會預設計 60 分鐘。要改某一節，回到「記錄」打開詳情，點鉛筆調整時間並儲存。

怎麼分享回顧？ 在「分析」選有練習資料的日期範圍，點右上角分享圖示。在「分享內容」取消不想公開的「含名稱」卡片，至少留一張。滑動核對預覽，選了展示老師或歌曲名稱的卡片，這些名稱也會出現在分享圖上。最後點右上角的分享圖示，選擇發送或儲存方式。

支援信箱 realrael.dev@outlook.com 。請寫上 App 版本、裝置型號、系統版本、卡在哪一步，以及螢幕提示的原文。影片問題請註明同一段能否在該裝置的「照片」裡播放。截圖可遮住名字和筆記。請勿附上備份檔案、密碼、驗證碼或私人影片。開發者無法查看或恢復你的私人 iCloud 資料。

網站託管

本支援及隱私權政策網站使用 GitHub Pages 託管。造訪這些網頁時，GitHub 會基於安全目的記錄並儲存訪客的 IP 位址，無論您是否登入 GitHub。相關資訊由 GitHub 依其隱私聲明處理。此處理發生於網站造訪，不表示 GloCue 在 App 內加入行為追蹤、廣告或第三方分析。詳情請參閱 GitHub 隱私聲明。
